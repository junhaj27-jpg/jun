# ALPLED

## sLLM 기반 멀티에이전트 개발 산출물 자동화 플랫폼

ALPLED는 RFP, 회의록, 화면 이미지, 기존 산출물 등을 기반으로 SDLC 개발 산출물을 자동 생성하고, 생성된 문서의 버전 관리, 수정, 승인 요청, 정합성 검토까지 지원하는 AI 기반 개발 산출물 자동화 플랫폼입니다.

본 프로젝트는 단순 문서 생성 서비스가 아니라, 개발 프로젝트에서 반복적으로 작성되는 요구사항 정의서, 사용자 인터페이스 설계서, 아키텍처 설계서, ERD, 데이터베이스 설계서, 통합 시험 시나리오를 하나의 흐름으로 생성하고 관리하는 것을 목표로 합니다.

---

## 1. 프로젝트 개요

개발 프로젝트에서는 RFP, 회의록, 요구사항 정의서, 화면설계서, DB 설계서, 테스트 시나리오 등 다양한 산출물이 작성됩니다.
그러나 실제 개발 과정에서는 각 문서가 개별적으로 작성되기 때문에 요구사항 누락, 화면 ID 불일치, 테스트 케이스 미연결, 산출물 버전 혼선, 승인 이력 관리 어려움 등의 문제가 발생할 수 있습니다.

ALPLED는 이러한 문제를 해결하기 위해 사용자가 프로젝트를 생성하고, 관련 문서를 업로드한 뒤, AI를 통해 주요 산출물을 순차적으로 생성하며, 생성된 산출물을 수정·승인·버전 관리할 수 있는 웹 기반 플랫폼으로 설계되었습니다.

---

## 2. 개발 배경

기존 개발 산출물 작성 과정에는 다음과 같은 한계가 있습니다.

* RFP와 회의록을 기반으로 여러 산출물을 반복 작성해야 함
* 요구사항 변경 시 화면설계서, DB설계서, 테스트 시나리오에 변경사항이 반영되지 않는 경우가 많음
* 산출물별 버전 관리가 수동으로 이루어져 최신본 확인이 어려움
* 문서 수정 시 누가 수정 중인지 확인하기 어려움
* 산출물 승인 요청과 검토 이력이 체계적으로 관리되지 않음
* 기업 내부 문서 특성상 외부 AI 서비스에 원문을 업로드하기 어려움

본 프로젝트는 이러한 문제를 해결하기 위해 sLLM, RAG, 문서 생성 에이전트, 검증 에이전트, 승인 워크플로우를 결합한 개발 산출물 자동화 플랫폼을 구현하고자 했습니다.

---

## 3. 개발 목표

ALPLED의 핵심 목표는 다음과 같습니다.

* RFP 및 회의록 기반 사용자 요구사항 정의서 생성
* 화면 이미지 기반 사용자 인터페이스 설계서 생성
* 아키텍처 구성요소 입력 기반 아키텍처 설계서 생성
* 선행 산출물 기반 ERD 및 데이터베이스 설계서 생성
* 요구사항과 화면설계 기반 통합 시험 시나리오 생성
* 산출물 버전 이력 관리
* 산출물 미리보기 및 다운로드
* OnlyOffice 기반 문서 수정 워크스페이스 제공
* 산출물 승인 요청 및 승인/반려 처리
* 변경 전후 비교 기반 정합성 검토
* 관리자, 프로젝트 관리자, 일반 사용자 권한별 화면 제공

## 4. 주요 기능

### 4.1 로그인 및 사용자 인증

사용자는 사원번호와 비밀번호를 입력하여 로그인할 수 있습니다.
최초 로그인 시 임시 비밀번호 사용자는 비밀번호 변경 안내를 받고 개인정보 수정 화면에서 새 비밀번호를 설정할 수 있습니다.

주요 화면:

* 로그인
* 임시 비밀번호 안내 
* 개인정보 수정

---

### 4.2 메인 페이지 및 프로젝트 선택

메인 페이지에서는 현재 프로젝트를 선택하고, 권한에 따라 사용할 수 있는 메뉴를 확인할 수 있습니다.

주요 메뉴:

* 사용자 관리
* 프로젝트 관리
* 파일 관리
* 산출물 버전 이력
* 사용자 요구사항 정의서
* 사용자 인터페이스 설계서
* 아키텍처 설계서
* 엔티티 관계 모형 설계서
* 데이터베이스 설계서
* 통합 시험 시나리오
* 산출물 승인 요청

주요 화면:

* 메인 페이지

---

### 4.3 사용자 관리

시스템 관리자는 사용자 목록을 조회하고, 사용자 등록, 상세 조회, 수정, 삭제, 임시 비밀번호 초기화, 활성 여부 변경을 수행할 수 있습니다.

주요 화면:

* 사용자 관리
* 사용자 상세
* 사용자 등록

---

### 4.4 프로젝트 관리

시스템 관리자는 프로젝트를 등록하고 프로젝트 관리자와 담당자를 배정할 수 있습니다.
프로젝트 관리자는 자신에게 할당된 프로젝트를 조회하고 일부 정보를 수정할 수 있습니다.

주요 화면:

* 프로젝트 관리 — 시스템 관리자
* 프로젝트 상세/수정 — 시스템 관리자
* 사용자 검색
* 프로젝트 등록
* 프로젝트 관리 — 프로젝트 관리자
* 프로젝트 상세/수정 — 프로젝트 관리자

---

### 4.5 파일 관리

사용자는 프로젝트에 필요한 RFP와 회의록 파일을 등록하고 관리할 수 있습니다.
등록된 파일은 검색, 다운로드, 삭제가 가능하며, 산출물 생성의 입력 데이터로 사용됩니다.

주요 기능:

* 문서 구분 필터
* 검색 조건 필터
* 파일 다운로드
* 파일 삭제
* RFP / 회의록 파일 등록
* 업로드 파일 용량 제한 검증

주요 화면:

* 파일 관리
* 파일 등록

---

### 4.6 산출물 생성

ALPLED는 프로젝트 문서와 선행 산출물을 기반으로 주요 개발 산출물을 순차적으로 생성합니다.

생성 대상 산출물:

1. 사용자 요구사항 정의서
2. 사용자 인터페이스 설계서
3. 아키텍처 설계서
4. 엔티티 관계 모형 설계서
5. 데이터베이스 설계서
6. 통합 시험 시나리오

주요 화면:

* 사용자 요구사항 정의서 생성
* 문서 불러오기
* 사용자 인터페이스 설계서 생성
* 아키텍처 설계서 생성
* 아키텍처 구성요소 입력
* 엔티티 관계 모형 설계서 생성
* 데이터베이스 설계서 생성
* 통합 시험 시나리오 생성

---

### 4.7 산출물 버전 이력

생성된 산출물은 버전 단위로 관리됩니다.
사용자는 산출물 종류별로 버전 이력을 조회하고, 미리보기와 다운로드를 수행할 수 있습니다.

주요 화면:

* 산출물 버전 이력
* 산출물별 버전 이력

---

### 4.8 산출물 수정 워크스페이스

사용자는 생성된 산출물을 미리보기 화면에서 확인하고, 수정 권한을 획득한 뒤 OnlyOffice 기반 워크스페이스에서 직접 문서를 수정할 수 있습니다.

주요 기능:

* 수정 점유자 확인
* 수정 권한 확보
* 다른 사용자 수정 중 안내
* 수정 이력 보기
* 파일 다운로드
* 문서 저장

주요 화면:

* 산출물 수정 미리보기
* 산출물 수정 워크스페이스
* 수정 이력 보기

---

수정된 산출물은 승인 요청을 보낼 수 있으며, 프로젝트 관리자 또는 시스템 관리자는 승인 요청된 산출물을 검토할 수 있습니다.
승인 상세 화면에서는 변경 전후 비교와 정합성 검토 결과를 확인하고, 승인 또는 반려 처리를 수행할 수 있습니다.

주요 기능:

* 승인 요청 내용 입력
* 승인 요청 목록 조회
* 승인 상태 필터
* 변경 전후 비교
* 정합성 검토
* 승인 처리
* 반려 처리
* 승인 이력 확인

주요 화면:

* 승인 요청 모달
* 산출물 승인요청
* 산출물 승인 상세 — 정합성 검토
* 산출물 승인 상세 — 요청 처리
* 요청 처리 — 승인
* 요청 처리 — 반려
* 산출물 승인 상세 — 이력 확인

## 5. 서비스 흐름

ALPLED의 전체 서비스 흐름은 다음과 같습니다.

```text
1. 사용자가 로그인한다.
2. 임시 비밀번호 사용자는 개인정보 수정 화면에서 비밀번호를 변경한다.
3. 메인 페이지에서 프로젝트를 선택한다.
4. RFP와 회의록 파일을 업로드한다.
5. 사용자 요구사항 정의서를 생성한다.
6. 화면 이미지를 기반으로 사용자 인터페이스 설계서를 생성한다.
7. 아키텍처 구성요소를 입력하고 아키텍처 설계서를 생성한다.
8. 선행 산출물을 기반으로 ERD를 생성한다.
9. ERD를 기반으로 데이터베이스 설계서를 생성한다.
10. 요구사항과 화면설계서를 기반으로 통합 시험 시나리오를 생성한다.
11. 생성된 산출물을 미리보기하고 다운로드한다.
12. 필요한 경우 OnlyOffice 워크스페이스에서 문서를 수정한다.
13. 수정된 산출물에 대해 승인 요청을 보낸다.
14. 관리자는 변경 전후 비교와 정합성 검토 결과를 확인한다.
15. 승인 또는 반려 처리 후 산출물 버전 이력에 반영한다.
```

## 9. 실행 방법

### 9.1 가상환경 생성

```bash
python -m venv .venv
```

### 9.2 가상환경 활성화

Windows 기준:

```bash
.venv\Scripts\activate
```

Git Bash 기준:

```bash
source .venv/Scripts/activate
```

### 9.3 패키지 설치

```bash
pip install -r requirements.txt
```

### 9.4 서버 실행

FastAPI 기준:

```bash
uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

Django 기준:

```bash
python manage.py runserver
```

### 9.5 접속 주소

```text
http://127.0.0.1:8000
```
